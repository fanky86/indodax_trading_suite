# 📦 Installation

## Clone Repository

git clone https://github.com/fanky86/indodax_trading_suite

cd indodax_trading_suite

---

# 🐍 Virtual Environment

python3 -m venv venv

Linux:
source venv/bin/activate

Windows:
venv\Scripts\activate

---

# 📥 Install Dependencies

pip install -r requirements.txt

---

# ⚙️ Configuration

Edit:

config.py

Isi API:

INDODAX_API_KEY = "YOUR_API_KEY"

INDODAX_SECRET_KEY = "YOUR_SECRET"

INDODAX_WS_TOKEN = "YOUR_WS_TOKEN"

---

# 🚀 Run Bot

python main.py
